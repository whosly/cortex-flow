About Token Tracking

Token statistics are tracked via TokenTracker, automatically integrated on each LLM call.

Access via ctx.token_snapshot() in DAG tasks or orchestrator.token_snapshot() at the orchestrator level.

Demo mode uses MockLLMClient — token data is simulated. Connect a real LLM API for actual tracking.
